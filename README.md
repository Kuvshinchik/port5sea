# 🧸 Toy AI Platform

Интерактивная веб-платформа, которая оживляет физические игрушки через AI, игры и персонализированный контент.

---

## 🚀 О проекте

Toy AI Platform — это Laravel-приложение, где ребенок взаимодействует с цифровым аватаром игрушки:

* 🤖 общается с AI
* 🎮 играет в мини-игры (Phaser)
* 📚 получает обучающий и развлекательный контент
* 🧠 получает персонализированный опыт

---

## 🧩 Основные возможности

* Профиль ребенка (ChildProfile)
* Интеграция с игрушкой (QR-код)
* AI-аватар
* Игры на Phaser
* Контентная система (из БД)
* Подписки (в разработке)

---

## 🏗 Архитектура

Тип: **Laravel монолит с API-слоем**

### Основные компоненты:

* **Blade (SSR)** — фронтенд
* **API (/api/v1)** — для игр и будущих клиентов
* **Phaser** — игровая логика
* **AI Service** — слой работы с AI
* **Content System** — управление контентом

## 🧠 AI архитектура

AI реализован через сервисный слой:

Controller → AIService → Provider

Провайдеры:

* LocalAIProvider (текущий)
* ApiAIProvider (будущий)

❗ AI не вызывается напрямую из контроллеров

## 🎮 Игры (Phaser)

## ⚙️ Установка

### 1. Клонирование репозитория

```bash
git clone <repo-url>
cd project
```

---

### 2. Установка зависимостей

```bash
composer install
npm install
```

---

### 3. Настройка окружения

```bash
cp .env.example .env
php artisan key:generate
```

---

### 4. База данных

```bash
php artisan migrate
```

---

### 5. Запуск

Если используется OSPanel — проект доступен через локальный домен.

Иначе:

```bash
php artisan serve
npm run dev
```
