# SYSTEM.md

## 🧩 Архитектура системы

Тип: монолит (Laravel) с возможностью роста

Компоненты:

1. Web (Blade)
2. API (для Phaser и будущих клиентов)
3. AI слой
4. Контентная система
5. Игровая система

---

## 🖥 Frontend

- Blade (SSR)
- минимальный JS
- Phaser игры подключаются отдельно

---

## 🎮 Игровая архитектура

Phaser:
- отдельный слой
- взаимодействует через API

Backend:
- хранит:
  - прогресс
  - результаты
  - события

---

## 🔗 API слой

Обязателен даже при Blade:

/api/v1/

Используется для:
- игр
- AI
- будущих клиентов

---

## 🤖 AI архитектура

Слой:

Controller → AIService → Provider

Provider:
- LocalAIProvider
- ApiAIProvider (будущий)

---

## 📚 Контентная система

Контент хранится в БД:

Таблицы:
- contents
- content_categories
- content_tags

Контент должен:
- легко расширяться
- фильтроваться

---

## 👤 Пользователи

### Сейчас:
- ChildProfile

### Будущее:
- Parent
- Parent → ChildProfiles (1:N)

---

## 🧸 Игрушки

Toy:
- привязан к ребенку
- содержит:
  - avatar
  - тип

---

## 💳 Подписки

Subscription:
- связана с пользователем
- управляет доступом к контенту
