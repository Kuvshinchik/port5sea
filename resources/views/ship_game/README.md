# 🚢 Инструкция по запуску игры "Теплоход"

## Файлы в комплекте:
1. **ship.png** - спрайт теплохода
2. **ship_game.html** - игра
3. **map_01.png** - твоя карта (уже загружена)

## Как запустить:

### Шаг 1: Подготовь файлы
Положи все файлы в одну папку:
```
моя_игра/
  ├── ship_game.html
  ├── ship.png
  └── map_01.png
```

### Шаг 2: Открой игру
Просто открой файл `ship_game.html` в браузере (двойной клик или правой кнопкой → "Открыть с помощью" → браузер)

### Шаг 3: Настрой координаты остановок
Координаты точек на карте сейчас примерные. Чтобы настроить их точно:

1. Открой файл `ship_game.html` в текстовом редакторе
2. Найди строки около 95:
```javascript
/*
this.input.on('pointerdown', (pointer) => {
    console.log(...);
});
*/
```

3. Удали `/*` и `*/` чтобы раскомментировать код
4. Открой игру в браузере и нажми F12 (откроется консоль разработчика)
5. Кликай по карте в нужных местах
6. В консоли увидишь координаты, например:
   `{ x: 780, y: 500, isStop: true, name: "Название" }`
7. Скопируй эти координаты и замени ими значения в массиве `routePoints` (строки 49-63)

## Особенности игры:

### Что работает:
✅ Теплоход автоматически движется по маршруту
✅ На остановках (чёрные кружки) появляются кнопки
✅ Корабль поворачивается по направлению движения
✅ Есть тень под кораблём и волны за ним
✅ Красивая анимация кнопок

### Элементы управления:
- **"Продолжить плавание"** - корабль плывёт к следующей точке
- **"Начать уровень"** - здесь нужно запустить твой игровой уровень

### Кастомизация:

#### Изменить скорость корабля:
Найди строку 260:
```javascript
const duration = distance * 8; // Чем больше число, тем медленнее
```

#### Изменить размер корабля:
Найди строку 144:
```javascript
ship.setScale(0.4); // Измени 0.4 на другое значение
```

#### Добавить больше остановок:
Добавь элементы в массив `routePoints`:
```javascript
{ x: 700, y: 450, isStop: true, name: "Новая остановка", level: 5 }
```

## Интеграция с игровыми уровнями:

Когда нажимается кнопка "Начать уровень", вызывается функция `startLevel`.
Найди её в коде (строка 329) и добавь свою логику:

```javascript
function startLevel(scene) {
    const currentStop = routePoints[currentPoint];
    
    // Вариант 1: Переход на другую сцену Phaser
    scene.scene.start('Level' + currentStop.level, { 
        stopName: currentStop.name 
    });
    
    // Вариант 2: Переход на другую страницу
    window.location.href = 'level' + currentStop.level + '.html';
    
    // Вариант 3: Показать iframe с уровнем
    // ... твой код
}
```

## Возможные проблемы:

❌ **Карта не загружается** - проверь, что файл `map_01.png` в той же папке

❌ **Корабль не виден** - проверь, что файл `ship.png` в той же папке

❌ **Координаты неточные** - настрой их по инструкции выше
